# AZUREFOUNDRY-TEST001

TERRAFORM HELLO-WORLD EXAMPLE FOR AZURE WITH A REUSABLE MODULE + WORKSPACE STRUCTURE.

## STRUCTURE

- `modules/AZURE_PUBLIC_VM`
  - REUSABLE MODULE FOR A PUBLIC-FACING LINUX VM
  - CREATES VNET, SUBNET, NSG, PUBLIC IP, NIC, AND VM
- `workspaces/HELLO_WORLD`
  - DEPLOYABLE WORKSPACE THAT CALLS THE MODULE
  - CREATES THE RESOURCE GROUP AND EXPOSES OUTPUTS

## QUICK START

1. AUTHENTICATE TO AZURE (EXAMPLE: `az login`)
2. GO TO THE WORKSPACE:
   - `cd workspaces/HELLO_WORLD`
3. CREATE YOUR VARIABLES FILE:
   - `cp terraform.tfvars.example terraform.tfvars`
   - UPDATE `SSH_PUBLIC_KEY`
4. INITIALIZE + VALIDATE + PLAN:
   - `terraform init`
   - `terraform validate`
   - `terraform plan`
5. APPLY:
   - `terraform apply`

## NOTES

- NAMING, VARIABLES, AND IDENTIFIERS USE UPPERCASE WHERE POSSIBLE TO MATCH REQUESTED STYLE.
- THE VM INSTALLS NGINX AND SERVES A HELLO-WORLD PAGE ON PORT 80.
